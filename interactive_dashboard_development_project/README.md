
# Interactive Dashboard Development Project

## Objective
Create an interactive dashboard to present business insights clearly using charts and visual analytics.

The project helps:
- Analyze sales and profit trends
- Visualize business performance
- Generate actionable insights
- Support decision-making using charts

---

## Files Included
- app.py → Main Python program
- business_data.csv → Sample business dataset
- sales_chart.png → Generated sales chart
- profit_chart.png → Generated profit chart
- requirements.txt → Required libraries

---

## Features
- Monthly sales analysis
- Profit trend visualization
- Business performance insights
- Chart generation using Matplotlib
- Beginner-friendly dashboard implementation

---

## How to Run

### Step 1: Install Python
Download Python:
https://www.python.org/downloads/

### Step 2: Install Required Libraries

pip install -r requirements.txt

### Step 3: Run the Program

python app.py

---

## Output
The program generates:
- Sales performance chart
- Profit trend chart
- Dashboard insights
- Actionable business suggestions
